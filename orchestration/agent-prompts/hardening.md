The authoritative ownership is execution-plan.md row H and its transfer rules. Edit only that assignment, including colocated tests; manifests/lockfile and other shared paths follow their named owner. ## Deliver

Run T08 and reconcile every requirement plus PRD §63/§68 with evidence. Exercise real compiled CLI, migrations/recovery, permissions/security/redaction, usability/accessibility, live provider/Gate journeys, service install and resource budgets. ## Constraints

No silent product redesign, new optional scope or waived required external flow. Contract changes still follow consumer notification/revalidation procedure. Do not deploy, push or merge protected branches merely because tests pass.

## Required validation

All T08 gates and affected feature checks after each fix. Review full requirement traceability and source clauses, not only happy-path tests. Any unavailable environment or account remains explicit BLOCKED. Use commands established in testing.md and report exact results rather than assumed success.

## Handoff and definition of done

Deliver verified readiness only if required evidence passes; otherwise report exact blocked/failed checks and next resolving action. Include changed interfaces/migrations, final revision and command/results. Readiness does not authorize deployment. Include changed paths/interfaces, tests and validation output summary, remaining assumptions/blockers, and the revision needed by downstream owners.
